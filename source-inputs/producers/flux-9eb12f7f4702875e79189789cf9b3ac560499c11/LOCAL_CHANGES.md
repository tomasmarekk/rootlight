# Local parser bridge

The complete upstream tree is retained unchanged at the pinned revision. The
`parser/` selection preserves the official AST, grammar, scanner actions and
ordinary syntax diagnostics. The controlled Ragel input and checked generated
Rust add typed native work/cancellation authority without changing token tables.
The controlled parser propagates `Result` through scanner/parser/conversion
calls, charges native construction/depth, and supports locations-only storage.
The original parser remains available for native compatibility controls.

Regex validation and time spellings longer than 35 UTF-8 bytes return explicit
unsupported-validation stops; neither produces a partially successful File.
Resource/cancellation stops also discard the File. Standard library allocation
outside checked reservations is not claimed to be a global heap guarantee.

Compilation uses checked-in generated Rust. It runs no generator, source
download, external build script or network acquisition. Ragel 7.0.1 and Colm
0.14.2 are generation prerequisites, separately authenticated during preparation.
No generator installation or version invocation occurs during compilation.

The selected local package aligns its exact regex pin from 1.12.2 to the already
reviewed workspace 1.13.0 input. The original upstream tree and native capsule
remain unchanged historical evidence. The actual standalone lock is refreshed
offline; the changed dependency frame requires a new native20 execution and
Rootlight integration tests. No source acquisition is introduced by this change.
